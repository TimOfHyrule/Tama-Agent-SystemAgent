# 致綠界科技：平台商方案洽詢

主旨：**平台商合作方案洽詢 — 團購平台之子商店分潤與代收付架構**

---

您好，

我們正在開發一個團購平台（暫稱 Chama），服務對象是個人團主。買家在平台下單，由團主
向廠商採購出貨。我們希望由綠界擔任金流，並將金流關係設計成「平台 + 子商店」的架構，
而非由平台自行代收轉付，因此想先確認貴公司是否有對應的平台商方案。

有五個問題想請教：

**1. 子商店與分潤**
綠界是否提供平台商方案，讓平台底下開立多個子商店（每位團主一個），買家付款直接入子商店
帳，平台再抽取固定比例或固定金額的服務費？分潤是由綠界於撥款時自動拆分，還是需要平台
自行對帳後另行請款？

**2. 撥款放行控制**
平台能否控制子商店的撥款時點？例如訂單成立後款項先行保留，待平台確認「已出貨／已取貨」
後再放行撥款給該子商店。若可行，是透過 API 觸發，還是僅能於後台操作？

**3. 信託歸屬**
在上述架構下，代收款項的信託義務歸屬於綠界或子商店，還是仍會落到平台身上？我們想確認
平台是否因此**不需要**自行開立信託專戶或取得電子支付相關許可。

**4. 貨到付款狀態推播**
若訂單使用超商取貨付款，綠界能否將取貨／未取貨／退貨等狀態即時推播給平台（webhook 或
API 查詢）？我們需要逐筆掌握取貨結果，才能與團主及廠商結算。

**5. 信用卡 Token 歸屬**
平台能否保有跨子商店共用的信用卡 token？亦即買家在平台綁卡一次後，於不同團主（不同
子商店）下單皆可沿用，而不需在每個子商店重新綁卡。

以上五題若有對應方案或文件，煩請提供；也歡迎安排電話或線上會議說明。

謝謝。

（署名／公司或個人身分／聯絡電話／Email）
